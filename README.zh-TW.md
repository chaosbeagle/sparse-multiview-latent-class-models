## 專案介紹

本專案建立稀疏多視角潛在類別模型的識別與可認證反演理論，將觀測設計的結構、
潛在成分的恢復、成分的科學意義，以及定量統計保證放在同一套數學架構中研究。

研究從部分相互重疊的三組聯合分布出發，以共用條件機率核與連通分量內的混合
權重連結各個局部視角。理論先刻畫所有與觀測相容的參數，再分析額外的語意資訊
如何確定潛在狀態的固定二元合併，以及合併後的敏感度、特異度與盛行率。

## 主要成果

- **由局部視角推導全域識別。** 以相容的邊置換與權重相關的重疊穩定子，完整
  描述觀測纖維。當各觀測三元組滿足 Kruskal 秩條件時，進一步將纖維刻畫為
  各連通分量上的置換軌道。
- **精確判定語意可識別性。** 以保留下來的置換給出固定二元解釋的識別判準。
  對角觀測族在固定狀態數下，可透過有限枚舉得到敏感度、特異度與盛行率的
  精確可達集合及尖銳界限。
- **建立可認證的定量反演。** 由明確的導數與曲率界推導局部反演估計；對符合
  指定條件的輸入，精確有理數區間覆蓋演算法最終會產生可獨立檢查的正分離
  證書，並由此取得全域反演界。
- **推導統計保證。** 將有效的分離界轉換為潛在子類別參數的有限樣本誤差界，並
  建立金標方向認證與有界條件相依誤差下的信賴集合。
- **量化計算限制。** 針對明確列舉的乘積方盒證書格式，證明葉節點數下界，
  再以精確有理數算例分析證書規模與所述充分樣本數公式的保守程度。

## 形式驗證與重現

Lean 原始碼涵蓋主要的識別、語意、條件化、統計與證書正確性結果。幾何證書
規模下界與部分算例由傳統數學證明及精確算術支持；[形式驗證對照表](docs/formal-coverage.md)
列出論文結果與各項形式宣告的對應關係。

專案提供論文、**475 個 Lean 輸入檔案**、稽核原始碼、依賴版本與建置工具，固定
使用 Lean **4.32.0** 及九項依賴的確切版本。[2026-10-09 驗證紀錄](verification/VERIFICATION_RECEIPT.json)
涵蓋 **159 個來源模組**的完整流程，公開的 Lean 輸入保留該次來源雜湊。檢查項目
與重現方式見[驗證說明](verification/README.md)及[建置說明](BUILD.md)。

執行獨立的精確算例：

```bash
python3 -I examples/verify_examples.py
```
